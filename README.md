# 家庭图书馆

记录家里买了哪些书、花了多少钱，以及每个家庭成员各自读到哪儿。
手机、平板、电脑同一套响应式界面，支持扫码录入和 EPUB / PDF 在线阅读。

邮箱注册登录，按家庭共享书库：一个人建家庭、发邀请链接，家里人加入后就能看到同一个书库，
各自记自己的阅读进度。一台服务器可以同时服务多个家庭，彼此数据隔离。

数据全部存在自己的机器上（`data/` 目录），不依赖云服务。

## 快速开始

```bash
npm install
npm start
```

启动后终端会打印本机和局域网访问地址。手机连同一个 Wi-Fi、访问局域网地址即可，
把页面「添加到主屏幕」就和 App 一样用（PWA，带离线缓存）。

第一次打开会进入登录页：注册账号 → 新建家庭（或用邀请码加入）→ 开始录书。
第一个注册的账号是站点管理员。

默认启用 https —— 浏览器只在 https 或 localhost 下才允许网页调用摄像头，扫码需要它。
证书首次启动时自动生成，是自签名的，手机第一次打开会提示「不安全」，选择继续访问即可。
不需要扫码可以用 `HL_HTTPS=false` 关掉。

## 功能

**账号与家庭**

- 邮箱 + 密码注册登录，忘记密码发邮件重置（链接 1 小时有效、一次性，重置后其它设备自动退出）
- 注册后发验证邮件；设置里可以改称呼、改密码、退出登录
- 家庭：创建者可以改名、换邀请码、移出成员、转让家庭；成员可以随时退出，回来时阅读记录还在
- 邀请：把 `/login.html?invite=邀请码` 发给家人，注册或登录后自动加入；也可以手动输入邀请码
- 每个账号自动有一份「阅读档案」；没账号的家人（比如小朋友）也可以加一份档案，由大人代记
- 书、购书记录、阅读进度、笔记、电子书全部按家庭隔离，别的家庭看不到
- 代理、书目来源、识别引擎、各种 Key 属于全站设置，只有站点管理员能看能改

没配 SMTP 时，找回密码 / 验证邮箱的邮件内容会打印在服务端控制台，局域网自用也能找回密码。

**录入**

- 扫书背条形码，识别到 ISBN 后自动查书目，点一下入库
- 拍版权页自动识别书名、作者、出版社、ISBN、定价、分册名
- 查不到书目时可以拍封面 + 手工填写
- 套装书友好：整套共用一个 ISBN、每册书名不同时，用丛书名 + 分册名区分，同 ISBN 只提示不拦截

**书目来源**（可在设置里逐个开关，并行查询、先到先显示）

豆瓣读书、Z-Library、Google Books、Open Library、微信读书。
查到的书目和封面都会写进本地数据库，之后浏览书架不再联网。
访问不到的来源可以在设置里开代理，改完即时生效。

**拍照识别引擎**（设置里切换）

- 本地 Tesseract：离线免费，`npm run ocr:setup` 下载模型即可使用
- AI 视觉模型：识别准确率高很多，走 OpenAI 兼容接口，填 base_url / model / API Key 就能用，
  内置几家国内厂商的预设

识别出 ISBN 后会自动再查一次书目，以书目库的权威数据为准；
版权页独有的信息（分册名、整套定价）保留识别结果。识别结果会逐字段列出来让你确认后再填表。

**阅读与记录**

- 在线阅读：目录跳转、字号、三种配色、翻页或滚动；阅读位置按「书 × 成员」分别保存，换设备接着读
- 划线笔记：阅读时选中文字即可保存，可全库检索
- 购买记录：一本书可记多笔（复本、再版、送人），含日期、渠道、实付、购买人
- 阅读状态：每位成员对每本书独立记录状态、进度、起止日期、评分、短评
- 统计：年度购书量与花费、每月趋势、成员阅读排行、渠道与分类分布

## 配置

代理、书目来源开关、识别引擎等全站设置由站点管理员在网页「设置」里改，存在数据库中，即时生效；
家庭名字由家庭创建者在「设置 › 家庭」里改。

启动参数放 `.env`（可从 `.env.example` 复制）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HL_PORT` | 8080 | 端口 |
| `HL_HTTPS` | true | 是否启用 https（扫码需要） |
| `HL_PUBLIC_URL` | 空 | 对外访问地址，邮件链接用它拼；对公网开放时必填 |
| `HL_ALLOW_REGISTER` | true | 是否开放注册，关掉后只能凭邀请链接注册 |
| `HL_ADMIN_EMAILS` | 空 | 站点管理员邮箱，逗号分隔；填了就只认名单，不填则第一个注册的是管理员 |
| `HL_SESSION_DAYS` | 30 | 登录有效期（天） |
| `HL_TRUST_PROXY` | 空 | 反向代理后面部署时设置，如 `1` |
| `HL_ZLIB_ENABLED` | true | Z-Library 来源的默认开关，公开站点建议 false |
| `HL_SMTP_HOST` / `HL_SMTP_PORT` / `HL_SMTP_SECURE` | 空 / 465 / true | 发信服务器 |
| `HL_SMTP_USER` / `HL_SMTP_PASS` / `HL_MAIL_FROM` | 空 | 发信账号、密码（授权码）、发件人 |
| `HL_BREVO_API_KEY` | 空 | Brevo 邮件 API Key，配了就优先用它发信（走 https，不受 SMTP 端口屏蔽影响） |
| `HL_UPLOAD_LIMIT_MB` | 200 | 单个电子书文件大小上限 |
| `HL_DATA_DIR` | `./data` | 数据目录 |

## 命令

```bash
npm start              # 启动
npm run ocr:setup      # 下载拍照识别用的 OCR 模型
npm run cert           # 重新生成自签名证书
npm run covers         # 补下载还没存到本地的封面
```

## 技术栈

Node.js 22+ / Express / `node:sqlite`（无需编译原生模块），
前端是原生 ES Module，没有构建步骤；
epub.js、pdf.js、ZXing 等前端依赖在 `npm install` 时从 node_modules 复制到本地，不依赖 CDN。

```
server.js       服务入口
src/            配置、数据库、账号与家庭、业务路由与各项服务（书目聚合、OCR、ISBN、发信…）
public/         前端 SPA 与在线阅读器
scripts/        证书、图标、OCR 模型、数据迁移等辅助脚本
data/           数据库、封面、电子书（整个目录拷走 = 完整备份）
```

## 部署成网站给别人用

GitHub 只存代码，跑不了 Node 服务；网站要部署到支持 Node / Docker 的平台上。仓库里已经带了 `Dockerfile` 和 `render.yaml`。

**Render（最省事）**

1. 登录 [render.com](https://render.com)（可以直接用 GitHub 账号）
2. Dashboard → **New → Blueprint** → 选这个仓库，Render 会读取 `render.yaml` 自动建好服务
3. 按提示填发信的环境变量，不填的话收不到找回密码、验证邮箱的邮件。
   Render 免费套餐屏蔽 SMTP 端口，推荐用 [Brevo](https://www.brevo.com)（免费每天 300 封）：
   注册后在 Senders 里验证一个发件邮箱，在 SMTP & API → API Keys 里生成 Key，
   然后只填 `HL_BREVO_API_KEY` 和 `HL_MAIL_FROM`（如 `家庭图书馆 <你验证过的邮箱>`）
4. 部署完得到 `https://xxx.onrender.com`，发给别人就能注册试用

注意：

- 免费套餐**没有持久化磁盘**，服务重启、重新部署后数据清空，只适合演示；
  长期使用把 `render.yaml` 里的 `plan` 改成 `starter` 并打开 `disk` 配置（约 $7/月）
- 免费套餐闲置 15 分钟会休眠，下次打开要等几十秒
- Render 会自动提供对外地址，`HL_PUBLIC_URL` 不用填
- 务必填 `HL_ADMIN_EMAILS`（你自己的邮箱）：不填的话谁先注册谁就是站点管理员；
  填了之后只有名单里的邮箱是管理员，已注册的账号重新登录一次即生效
- 公开站点默认关闭 Z-Library 来源（`HL_ZLIB_ENABLED=false`）
- 只想让熟人试用：`HL_ALLOW_REGISTER=false`，第一个人注册后发邀请链接给其他人

**其它平台 / 自己的服务器**

Railway、Zeabur、Fly.io 都能直接用 `Dockerfile` 部署；自己的服务器上：

```bash
docker build -t home-library .
docker run -d -p 8080:8080 -v $(pwd)/data:/data \
  -e HL_PUBLIC_URL=https://books.example.com -e HL_TRUST_PROXY=1 \
  --env-file .env home-library
```

前面用 nginx / Caddy 配 https。数据都在挂载的 `data/` 目录里。

## 从单机版升级

老版本（没有账号的版本）的数据库启动时会自动升级：原来的书和成员归入一个「待认领」的家庭，
**第一个注册的账号**自动成为它的创建者，并接管原来的第一个成员档案，阅读记录原样保留。
之后在「设置 › 家庭」里复制邀请链接发给家里人即可。原来的 `HL_PIN` 口令已不再使用。

## 备份

`data/` 目录就是全部数据（所有家庭）。「设置 › 备份与导出」可以导出本家庭的 JSON 或 CSV。

## 说明

- 书目来源中的 Z-Library 只用于取书目文字信息，不做任何验证绕过、也不下载书籍文件；
  站上多数书籍是未授权副本，请自行判断使用方式。
- 各来源接口均为公开访问，请合理控制请求频率。
