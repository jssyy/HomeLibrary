# 家庭图书馆

记录家里买了哪些书、花了多少钱，以及每个家庭成员各自读到哪儿。
手机、平板、电脑同一套响应式界面；支持**手机扫码录入**和**EPUB / PDF 在线阅读**。

数据全部存在你自己的机器上（`data/` 目录），不依赖任何云服务。

---

## 快速开始

```bash
npm install
npm start
```

启动后终端会打印访问地址：

```
本机：     https://localhost:8080
手机/平板： https://192.168.0.105:8080   （WLAN）

已略过 3 个虚拟网卡地址（VMware / TUN 代理之类，手机连不上）：
  192.168.117.1、192.168.80.1、198.18.0.1
```

机器上通常同时存在一堆虚拟网卡（VMware、Hyper-V、WSL、Clash TUN 的 198.18.x 等），
它们的地址手机是连不上的，所以启动时会自动按网卡名 / MAC 厂商前缀 / 网段特征筛掉，
只推荐真正的局域网地址（判断逻辑在 `src/net.js`）。

手机连同一个 Wi-Fi，直接访问推荐的那个地址即可。证书是自签名的，
首次打开浏览器会提示"不安全"，选「继续前往」。

**手机打不开？** 依次检查：手机和电脑是否在同一个 Wi-Fi（别连成热点或访客网络）；
Windows 防火墙是否放行（管理员 PowerShell 执行
`New-NetFirewallRule -DisplayName "HomeLibrary" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow`）；
路由器的「AP 隔离 / 客户端隔离」是否开着。这几条启动时也会打印出来。

> **为什么默认开 https？** 浏览器只在 https 或 localhost 下才允许网页调用摄像头，
> 手机扫码必须要它。证书在首次启动时自动生成，并包含本机所有局域网 IP。
> 不需要扫码的话可以 `HL_HTTPS=false npm start` 换回 http。

把页面「添加到主屏幕」，用起来就和 App 一样（PWA，已带离线缓存）。

## 主要功能

### 📷 扫码录入
对准书背条形码即可，识别到 ISBN 后自动向各书目来源查询，点一下入库。

- 优先用浏览器原生 `BarcodeDetector`，不支持则自动回落到 ZXing（已本地打包，不连 CDN）
- 没有摄像头/不给权限时：手动输 ISBN、或拍一张条码照片识别
- **查不到书目也能录入**：点「📷 拍封面录入」直接拍书封，其余信息手填
- **套装书同 ISBN 也能分别录入**：整套共用一个 ISBN、每册书名不同（比如《中国神话故事》和
  《希腊神话故事》同属一套），录入时会提示"已有 N 本同 ISBN 的书"，由你选择打开已有的那本，
  还是填个分册名当作新分册入库；书名完全相同时才判定为真正的重复

### 📖 拍版权页自动录入
对着版权页（或 CIP 数据页）拍一张，自动填书名、作者、出版社、ISBN、定价、分册名。
录入页和扫码页都有「📷 拍版权页识别」按钮，识别完会列出每个字段让你勾选确认，
可以展开看识别原文核对。

两种识别引擎，在「设置 › 拍照识别版权页」里选：

| 引擎 | 中文识别 | 说明 |
|---|---|---|
| 本地 Tesseract | 一般（70~90%） | 离线、免费、零配置。`npm run ocr:setup` 下载模型（中文 2.4MB + 英文 3.9MB） |
| AI 视觉模型 | 很好 | 填个 API Key 就行，国内直连。智谱 GLM-4V-Flash **完全免费**，通义千问 VL、豆包也有免费额度 |

**为什么本地识别也够用**：中文印刷体 OCR 不可靠，但 **ISBN 那 13 位数字认得准**
（数字容错高，而且 ISBN 自带校验位可以自校验、自动纠正 O/0、l/1 这类形近误识）。
所以流程是「OCR 认 ISBN → 拿 ISBN 去豆瓣查权威书目」，本地引擎下中文字段以书目库为准，
只有版权页独有的信息（分册名、整套定价）才采用识别结果。配了 AI 模型则反过来，以识别结果为准。

> 实测（一张清晰的版权页）：本地引擎 2.5 秒，ISBN / 作者 / 出版社 / 出版时间全对，
> 书名偶尔多认一两个字，定价那行容易糊——这些用 AI 引擎就没问题。

### 📚 书目来源（可在设置里逐个开关）

| 来源 | ISBN 查询 | 关键字 | 说明 |
|---|---|---|---|
| 豆瓣读书 | ✅ | ✅ | 国内直连，中文书信息最全（作者/出版社/定价/评分/简介/封面） |
| Z-Library | ✅ | ✅ | 需在设置里填你登录后的 Cookie，详见下文 |
| Google Books | ✅ | ✅ | 中英文都不错，需要能访问外网，建议自备 API Key |
| Open Library | ✅ | ✅ | 免费无需 Key，英文书全、中文书弱 |
| 微信读书 | ❌ | ✅ | 国内直连，中文书名搜索最好用 |

各来源**并行查询、先到先显示**，不会被最慢的那个拖住。
查到的信息（含封面）会**写进本地数据库**，之后翻书架、看详情都是纯本地读取，不再联网。

外网来源在国内通常要走代理：**设置 › 网络代理**里打开开关、填地址（如 `http://127.0.0.1:7897`），
改完即时生效，不用重启。旁边的「连通性自检」会逐个测试各来源通不通。

### 📖 在线阅读
给书上传 EPUB / PDF 后即可在浏览器里读：

- 目录跳转、字号调节、白/米/夜三种配色、翻页或滚动
- **阅读位置按「书 × 成员」分别保存**（EPUB 存 CFI，PDF 存页码），换设备接着读
- 读到 100% 自动标记「已读」
- 选中正文文字 → 存为划线笔记，笔记页可全库检索

### 📦 套装书 / 系列书
一套书往往整套只有一个 ISBN，但每册书名不同。书里用 `series`（丛书/套装名）+ `volume`（分册）
两个字段来表达，详情页会列出"同一套的其它分册"并互相跳转；ISBN 只作提示，不做唯一约束。

### 🧾 购书记录与阅读情况
- 一本书可以有多条购买记录（复本、再版、送人），记录日期、渠道、实付、购买人
- 每位成员对每本书各有独立的：状态（待读/在读/已读/弃读）、进度、起止日期、评分、短评
- 统计页：年度购书量与花费、每月趋势、各成员阅读排行、渠道与分类分布

## Z-Library 接入

Z-Library 站点前面有 DiamWall 浏览器验证，服务端匿名访问会被 307/513 挡住。
**这里不做任何验证绕过**，提供两条正规路径（都只取书目文字信息，不下载书籍文件）：

**① 填 Cookie（推荐）**
浏览器登录 Z-Library → F12 → Network → 任意请求 → Request Headers → 复制整行 `cookie`
→ 粘贴到「设置 › Z-Library › Cookie」。之后扫 ISBN 就能直接从 Z-Library 取书目入库。

**② 书签小工具**
「设置 › Z-Library › 获取书签代码」，把按钮拖到书签栏。
在 Z-Library 的书籍页点一下，书目会自动带回本地的录入页，确认即可入库。

书籍文件请你自己在浏览器里下载，再回到书库上传，就能在线阅读了。
书籍详情页底部的「Z-Library」按钮会按 ISBN/书名直接打开对应搜索页。

> 站点镜像域名经常变动，打不开时在设置里换一个地址即可。
> 另外提醒一句：Z-Library 上多数书籍是未授权副本，请自行判断使用方式。

## 从旧库迁移

已经把 `book_library/library.db` 里的 **240 本书**导入完毕，包括：

- 书目信息、豆瓣评分与简介、载体（纸质/电子）
- `爸爸已读|妈妈待读|凡凡待读` 这类拼接字符串，拆成了每位成员一条阅读记录
- 240 张封面已下载到 `data/covers/`，断网也能正常显示

需要重新跑或迁移其它库：

```bash
node scripts/migrate-old-db.js [旧库路径] [--covers]
node scripts/fetch-covers.js           # 单独补下载封面
npm run ocr:setup                      # 下载拍照识别用的 OCR 模型
```

> 旧库里没有购买日期和实付金额，所以**购买记录是空的**（统计里的"花费"暂时为 0）。
> 定价已经保留在每本书上；以后买新书时在详情页记一笔，统计就会累计起来。

## 配置

运行时配置（代理、书目来源开关、Cookie、书库名字…）都在网页「设置」里改，存在数据库中，即时生效。

启动参数放 `.env`（可从 `.env.example` 复制）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HL_PORT` | 8080 | 端口 |
| `HL_HTTPS` | true | 是否启用 https（扫码需要） |
| `HL_PIN` | 空 | 家庭访问口令，留空表示局域网内免登录 |
| `HL_UPLOAD_LIMIT_MB` | 200 | 单个电子书文件大小上限 |
| `HL_DATA_DIR` | `./data` | 数据目录 |

## 目录结构

```
server.js              服务入口（http/https、静态资源、路由挂载）
src/
  config.js            启动配置
  db.js                SQLite 建表（node:sqlite，无需编译原生模块）
  settings.js          运行时设置（存数据库，界面可改）
  util.js              公共小工具
  services/
    metadata.js        多来源书目聚合、封面本地化
    douban.js          豆瓣读书
    zlibrary.js        Z-Library（Cookie 查询 + 书签小工具 + 外链）
    ocr.js             本地 OCR（tesseract.js）与版权页字段解析
    vision.js          AI 视觉模型识别（OpenAI 兼容接口，可换厂商）
    isbn.js            ISBN 校验与 10/13 位互转
    http.js            统一外网出口（按设置走代理）
  routes/
    books.js           书籍、购买记录
    reading.js         成员、阅读状态、打卡、笔记
    files.js           电子书上传/读取（支持 Range）/封面
    meta.js            书目查询、Z-Library、设置、统计、导出
    ocr.js             拍照识别
public/
  index.html + js/     前端 SPA（原生 ES Module，无构建步骤）
  reader.html + js/reader.js  在线阅读器
  vendor/              epub.js / pdf.js / ZXing / JSZip（本地打包，不连 CDN）
scripts/
  gen-cert.js          自签名证书
  gen-icons.js         PWA 图标
  vendor.js            从 node_modules 拷前端依赖
  setup-ocr.js         下载 OCR 语言模型
  migrate-old-db.js    旧库迁移
  fetch-covers.js      封面回填
data/                  数据库、封面、电子书（整个目录拷走 = 完整备份）
```

## 备份

`data/` 目录就是全部家当：`library.db`（数据库）、`covers/`（封面）、`files/`（电子书）。
另外「设置 › 备份与导出」可以导出 JSON（完整备份）或 CSV（Excel 打开）。
